# AMOS Desktop 1.0.52

Hosted responses now preserve every streamed text fragment, including repeated words, indentation and code. This fixes answers that could lose content while streaming into Desktop.

Desktop also retains the actual served model, requested tier and fallback information when the hosted service provides them. Missing serving metadata remains unknown.

This patch keeps the existing manual tier controls and router model. Model availability and hosted model versions remain managed by the platform.
