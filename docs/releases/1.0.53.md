# AMOS Desktop 1.0.53

Desktop gives malformed tool calls clearer errors and more specific automatic correction guidance. It validates the entire response before running any tool and explains when retries are exhausted. File-edit recovery respects tools that replace a complete file.

Failed attempts now retain their model identity, usage and diagnostic details when the hosted service supplies them. Manual-tier activity shows the model that actually answered, and output-limit information survives trailing stream metadata.

The calculator now supports euro amounts and same-currency cash-runway calculations, with stricter operand validation.

This patch does not change hosted model weights. The original landing-page failure has not yet been attributed to a particular model or cause; these changes improve recovery and make subsequent failures diagnosable.
